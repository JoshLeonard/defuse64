For the Commodore 64. One player sits at the computer with the bomb. Everyone else reads this manual. The person holding the bomb may not look at this manual. The people holding the manual may not look at the screen. Talk to each other. Work fast.

How to play FOR EVERYONE

Each level is a bomb with one or more modules. Every module must be disarmed before the timer reaches zero. A mistake earns a strike. When the bomb reaches its strike limit it explodes. Each strike also makes the timer run faster.

The Defuser describes what they see. The Experts find the right page and give instructions. Modules are disarmed in any order. When a module is disarmed, the light in its top right corner turns green.

Loading the game

Attach defuse64.d64 and type LOAD"*",8,1 then RUN, or simply autostart defuse64.prg in VICE.

The bomb has a front and a back, each with room for six modules. Bigger bombs use both, so turn the bomb to find every module. The edgework is on the four edge faces (see The bomb casing).

A yellow frame marks the module the cursor is on. Press fire to work on it: the frame turns green and the controls now operate that module. Dark frames with four screws are empty spaces.

While you are inside a module, the stick and cursor keys work that module (for example, moving in a maze). Press DEL to return to the bomb before picking another module.

The bomb casing EDGEWORK

The bomb is a box with six faces. The front and back hold the modules. The left, right, top and bottom faces carry the edgework: the serial number, batteries, indicators and ports. Many modules need it, so the defuser has to turn the bomb and read it out.

Turning the bomb

  • Push past the edge of the modules in any direction and the bomb turns that way. Keep pushing to go all the way round.
  • Left / right goes round front → right → back → left. Up / down goes round front → top → back → bottom. From the left or right face, up and down take you to the top and bottom.
  • F1 or F swaps front and back, or returns to the front from an edge face.
  • The name of the face you are looking at is shown under LEVEL. The dots in the top right are a map of the bomb; the yellow one is the face on screen.

What you can find on the edges

The edgework is scattered at random, so each bomb is different. A face can be empty.

The top line

LEVEL 012   TIME 04:59   STRIKES X-: level, time remaining and strikes so far. Each X is a strike. Each - is one you can still afford: the bomb explodes on the next strike after the last -. With no marks at all, the first strike explodes the bomb.

  • The serial number is always six characters and always ends in a digit. "The last digit of the serial number" means that final character.
  • The vowels are A, E, I, O and U. (The letter O is never used in serial numbers, so a 0 is always a zero.)

On the Subject of Wires MODULE

A wires module has 3 to 6 horizontal wires. Wires are numbered from the top down. The letter at the left of each wire names its colour: Red, Blue, Yellow, White, blacK. Exactly one wire must be cut. Find the section for the number of wires and use the first rule that applies.

3 wires

  1. If there are no blue wires, cut the second wire.
  2. Otherwise, if the first wire is white, cut the third wire.
  3. Otherwise, if there is exactly one red wire, cut the red wire.
  4. Otherwise, cut the first wire.

4 wires

  1. If there is more than one yellow wire and the last digit of the serial number is even, cut the last yellow wire.
  2. Otherwise, if the last wire is black and there are no red wires, cut the first wire.
  3. Otherwise, if there is exactly one blue wire, cut the fourth wire.
  4. Otherwise, if there is more than one white wire, cut the first white wire.
  5. Otherwise, cut the second wire.

5 wires

  1. If the fifth wire is red and the last digit of the serial number is odd, cut the fourth wire.
  2. Otherwise, if there are no black wires, cut the first wire.
  3. Otherwise, if there is exactly one yellow wire and more than one white wire, cut the third wire.
  4. Otherwise, if there are more than two batteries, cut the fifth wire.
  5. Otherwise, cut the second wire.

6 wires

  1. If there are no white wires and the last digit of the serial number is odd, cut the third wire.
  2. Otherwise, if there is exactly one red wire and more than one blue wire, cut the last blue wire.
  3. Otherwise, if there are no yellow wires, cut the sixth wire.
  4. Otherwise, if there is a lit indicator labelled FRK, cut the first wire.
  5. Otherwise, cut the fourth wire.

On the Subject of The Button MODULE

A large coloured button (red, blue, yellow or white) with a word on it. Use the first rule that applies.

  1. If the button is red and says PRESS, press and immediately release it.
  2. If the button is blue and there are two or more batteries, hold the button.
  3. If the button says ABORT and there is a lit indicator labelled SIG, press and immediately release it.
  4. If the button is white and the serial number contains a vowel, hold the button.
  5. If the button says HOLD, press and immediately release it.
  6. If the button is yellow and there are no batteries, press and immediately release it.
  7. Otherwise, hold the button.

Holding the button

Keep fire held down. After a moment a coloured strip lights up beside the button. Release when the countdown timer shows the digit below in any position (for example 03:41 contains a 4).

On the Subject of Simon Says MODULE

Four coloured buttons in a diamond: blue (top), yellow (left), green (right), red (bottom). The module flashes a sequence. For each flash, press the button given by the table below. Each time you get the full sequence right, the sequence grows by one flash. Use the stick to choose a button and fire to press it.

On the Subject of Mazes MODULE

A 6×6 grid with two green circles, a white dot (you) and a red triangle (goal). The walls are invisible to the defuser. Find the maze whose green circles match — any one circle is enough — and guide the white dot to the triangle. Moving into a wall or off the edge is a strike (the dot does not move). In the module, the stick moves the dot directly.

On the Subject of Morse Code MODULE

A light flashes a word in Morse code, then pauses for a long gap and repeats. A short flash is a dot, a long flash (three times longer) is a dash. Letters are separated by a short pause. Work out the word, then set the frequency with left/right and press fire to transmit. A wrong frequency is a strike.

On the Subject of Venting Gas NEEDY MODULE

Needy modules can never be disarmed. They wake up from time to time and must be dealt with before their own countdown runs out, or the bomb takes a strike. You do not need them to win.

When the display asks a question, choose YES or NO with left/right and press fire:

DisplayAnswer
VENT GAS?YES
DETONATE?NO

The wrong answer is a strike.

Levels & codes APPENDIX

There are 100 levels. Bombs grow from one module to ten (plus up to two needy modules), the time allowed per module shrinks, and the modules themselves get harder (more wires, longer Simon sequences, faster gas). From level 70 the bomb explodes on the second strike; from level 90 on the first. Each bomb is randomly built, so replaying a level gives a new bomb.
